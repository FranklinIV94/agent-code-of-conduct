# Runbooks

Operational procedures that implement the Code of Conduct's mechanisms.

- **key-provisioning.md** — issue / rotate / emergency-rotate API keys (enforces §XVII D9, §X.5)
- **branch-protection.md** — deploy-branch protection + deploy-lock settings (enforces §XVII D2, D3, D5)

Each runbook names an owner and the Code sections it enforces. Changes follow the amendment procedure (§XIII).
